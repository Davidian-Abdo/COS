# OCOS — Open Construction Operating System
- OCOS is an open-source, AI-native operational runtime for construction: it turns scattered project information into coordinated, authorised and traceable action, starting with work-package readiness and constraint resolution — make-ready for a site team, fed by the messages and spreadsheets they already use (v1.0.0).
